03 / LOCAL AI

JARVIS Local v3

A local personal AI assistant combining task prioritization, persisted state, natural-language handling, voice support and a locally hosted model interface.

Bundled approved design reference; it is not evidence of a live deployed interface.

The problem

Daily task and schedule decisions can be scattered across notes, reminders and conversations. A local assistant can provide structured prioritization and recurring context without relying on a single cloud interface.

How the system is structured

  • Flask application and core Python modules handle local requests.
  • SQLite database stores persistent task and schedule context.
  • Local Ollama integration is configured, including model fallback behavior.
  • Voice output options include Kokoro, Piper and Windows speech.
  • An included self_test.py exercises scheduling, persistence, intent handling and fallback conditions.

Evidence & limitations

Reviewed Python source files and self_test.py from JARVIS_LOCAL_V3_0_9_COMPLETE. The shown visual is the supplied design-reference asset.

Implementation and test code present in archive; self-tests not executed in this portfolio build. The code was developed with significant AI assistance. Descriptions here refer to visible implementation and do not imply independent production verification.

Next engineering improvements

  • Run and document the included self-test suite on a clean installation.
  • Separate code from the bundled .venv environment and prepare reproducible setup instructions.
  • Record a real screen capture of task creation, retrieval and schedule decisions.
  • Document limitations of offline models, voice behavior, and local-only deployment.
