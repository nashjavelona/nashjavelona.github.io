# Nash Javelona - AI Automation & Technical VA Portfolio

Static, responsive website containing three documented technical projects: ROSE AI Messenger Automation, TimeLens World, and JARVIS Local. The PDF/Word resumes included in `assets/` are the corrected versions (skills-first summary; education stated as undergraduate coursework; no claim of a completed degree).

## Preview locally
Open `index.html` or, for a closer-to-production preview, run `python -m http.server 8000` inside this folder and visit `http://localhost:8000`.

## Publish
Upload **the contents of this `Portfolio_Website` directory** to a static host such as GitHub Pages, Netlify, or Vercel. This package does not automatically deploy the site, create repositories, or connect accounts. Confirm that `/`, `/projects/rose.html`, `/projects/timelens.html`, `/projects/jarvis.html`, and `/assets/Nash_Javelona_Resume.pdf` load on the public domain.

## Before sending your application
- Replace illustrative TimeLens and JARVIS images with real, sanitized product screenshots after validating the running apps.
- Do not upload private ThenNow/n8n archives or customer data. Rotate exposed API keys and remove OAuth tokens and sensitive files before publishing source code.
- Record short demos of real workflow runs; add only genuine links after they are public and safe.
- Add your deployed portfolio URL to the resume and re-export both DOCX and PDF.
- Confirm the contact email and phone number are correct.
- Answer education and employment-history questions truthfully on all application forms.

## Scope
The website is a **static portfolio**, not a live CRM or hosted automation. Current case studies describe source/configuration evidence and explicitly identify work that has not been independently validated end-to-end. No ranking or hiring outcome can be guaranteed by portfolio formatting.
